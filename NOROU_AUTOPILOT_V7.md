# Norou AI OS v7 — Autopilot & Agent Control

- Universal Command Centre now has Command, Autopilot, History and Permissions tabs.
- Agent actions are permission-gated with Allow / Ask first / Block controls.
- Every executed command stores a local pre-action snapshot for one-tap undo/history.
- Autopilot creates a local, priority-aware focus plan from open tasks and can start the next focus block.
- AI/local state is visible in the Command Centre; offline mode never claims web research or AI execution.
- Hologram states now distinguish idle, listening, thinking, planning, executing, success and offline/local mode.
