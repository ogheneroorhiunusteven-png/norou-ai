# Norou OS v2

This upgrade adds a deeper operating layer on top of the existing Norou app.

## Added
- Context Engine: combines today's calendar, goals, tasks and recent notes.
- Autopilot: creates a safe suggested action sequence from current tasks and goals.
- Hologram status states: idle, thinking, planning and searching.
- Skill Tree: Coding, Education, Fitness, Discipline and Cloud progress signals.
- Norou Tutor: AI teaching + self-check questions.
- Personal Knowledge Graph summary connecting goals, tasks, notes, memories, events and workouts.
- Quick Actions for Autopilot, Tutor, notes and focus tasks.
- Permission Centre persisted locally with Off / Read / Suggest / Ask first levels.
- Existing Vision Mode, planner, task breakdown, Goal Command, analytics and XP remain.

## Safety model
Autopilot is deliberately suggestion-first. This build does not silently send messages, book appointments, delete data or perform other consequential external actions.
