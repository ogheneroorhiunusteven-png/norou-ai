# Norou Money

Norou Money is a local-first monthly budgeting workspace.

## Current features
- Monthly income and left-to-budget overview
- Month navigation for stored expense history
- 50/30/20 starting framework with editable percentages
- Needs / Wants / Savings targets and progress
- Spending pace, projected month-end spend, and remaining days
- Expense search and category filters
- Add, edit, and delete expenses
- Local persistence through the existing Norou state store
- No bank connection or paid finance API required

The 50/30/20 split is presented as a general planning framework, not personal financial advice. Users can change the split to fit their own circumstances.
