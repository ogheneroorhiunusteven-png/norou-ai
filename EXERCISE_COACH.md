# Norou Exercise Coach

Norou now includes an animated exercise-teaching interface inspired by the supplied reference recording.

## Included
- Animated demonstration area with play/pause.
- Individual exercise selection.
- Step-by-step form cues.
- Primary and secondary muscle-group labels.
- Common-mistake guidance.
- Reduced-motion support for accessibility.
- Exercise Coach entry point on the Health screen.

The first built-in library contains Bench Press, Bodyweight Squat, Deadlift, Push-Up, Dumbbell Row and Reverse Lunge.

The animation is intentionally a lightweight local SVG/CSS-style figure rather than a copied asset from the reference recording. This keeps it fast and offline-friendly while leaving room to replace the figure with higher-fidelity licensed 3D exercise assets later.
